Plus Jakarta Sans: geometric with humanist stroke endings, so a single vocabulary word set large reads as designed rather than as default system text. This is the app's only visual signature, and it is spent on exactly one thing — the review card prompt. Everything else on this card exists so that a screen which genuinely needs a larger step has one to take rather than a number to invent.

A variable font, and the weight moves the wght axis rather than asking the renderer to fake one. A face declared at 400 and asked for 700 is synthesised — the outline is smeared rather than redrawn, and at display sizes that is visible.
