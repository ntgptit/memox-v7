Iconography

28 glyphs, and the set is closed. MxIcon takes a name from this list and nothing else — no src, no children, no inline SVG at a call site. The moment a caller can supply a shape, two screens draw two different bins and no reviewer can tell an intentional variant from a paste. An unknown name renders nothing and warns, so a typo fails where it is written.

Drawn on a 24 grid with round caps and joins, and every glyph inherits currentColor: an icon inside a control is the control's colour, which is what stops a glyph and its label drifting apart when someone restyles one of them.

Three sizes, three stroke weights
sm · 16
stroke 1.75
md · 24
stroke 1.5
lg · 40
stroke 1.25

The weight is set per step rather than left to scale with the box. A 1.5 stroke on a 24 grid is 2.5 device px once the box grows to 40, which turns the illustrative icon in an empty state into the heaviest mark on the screen; the same stroke shrunk to 16 is 1.0 and starts to break up. The set reads as one weight at all three sizes rather than one number at all three sizes.

Where each size goes
SizeUsed by
sm 16Inline with body text — a button's leading glyph, a pill's, a breadcrumb separator.
md 24Actions and list affordances — icon buttons, list rows, sheet rows, navigation destinations.
lg 40The illustrative icon in an empty or error state. Nothing else.
  • Decorative by default. An icon beside its own label is aria-hidden; the text is what is announced. A glyph that repeated the label would be read twice.
  • Named only when it is the content — and even then the name says what the state means, not what the shape is.
  • An icon-only control's label belongs on the control, not on the glyph. MxIconButton requires one.
  • No colour prop. Everything inherits.
