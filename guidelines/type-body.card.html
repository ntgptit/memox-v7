Body

Inter: drawn for screens — tall x-height, open apertures, unambiguous l / I / 1 — which is what a definition read at 14px on a phone actually needs. It carries an optical-size axis as well, so a body size and a display size are drawn differently rather than scaled.

Sizes are px and not rem. Flutter's logical pixels do not scale with a root font size, and a mirror that silently did would drift from the app on the first user who changes their browser default. User text scaling moves --mx-type-scale instead, which moves the whole scale together and keeps the ratios it was drawn with.
