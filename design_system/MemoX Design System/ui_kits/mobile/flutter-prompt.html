Flutter handoff specs

One design specification per widget in the kit, written for an agent that has the Flutter repository and not this design. Exact values are the deliverable: both themes, the type scale, spacing roles, every dimension tagged FIXED / MINIMUM / CONTENT-DRIVEN / SYSTEM-OWNED, the state matrix, and the web techniques that must not be copied literally. Copy it into your coding agent as-is.

—



Run Foundations once, then one widget spec per task — the widget specs omit the token, colour, type and composition sections on purpose, so you are not paying for them 46 times. Every value is read from colors_and_type.css at page load, for both themes, so the extracted spec cannot drift from the design. Component facts come from the widget's gallery card.
