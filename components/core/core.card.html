Core components

The eight components every screen is built from. Each takes an intent — a variant, a selected flag, an elevation step — and never a colour: appearance belongs to the system, so a screen cannot invent a shade that looks correct in isolation and wrong beside the others. Both modes are shown together because every decision here was made against the pair, not against one of them.
